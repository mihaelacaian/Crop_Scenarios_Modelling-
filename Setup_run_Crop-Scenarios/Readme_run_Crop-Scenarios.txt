Set-up for climate-crop multi-model scenarios, under various management practices; it uses:
  - input climate data from the output of "Preproc_Clim_to_crop" coupling to cromp model (*WTH file)
  - set-up user-choice for climate scenario, model, time-interval, region (SOIL.txt)
  - set-up user-choice for management practice (default has 12 planting dates x 3 fertilization levels), and genotype sensitivity       simulations;
  - set-up of extended configuration to run in seasonal forecast mode
